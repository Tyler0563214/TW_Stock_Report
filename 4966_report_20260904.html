🏢 公司概覽：高速介面 IC 的技術護城河
📌 Parade Technologies（譜瑞-KY）是什麼公司？
成立於 2005 年、2011 年在台灣上市（上市非上櫃，後轉至 TPEx）的無晶圓廠半導體公司（Fabless IC）。核心產品是「高速數位介面 IC」—— 讓電腦、顯示器、手機之間的影像與數據傳輸更快、更穩、更省電的小晶片。
簡單說：您用 DisplayPort 線把電腦接到螢幕，或用 USB-C 傳輸影像，背後的信號轉換晶片很可能就是譜瑞做的。
項目內容
核心產品線① DisplayPort 2.1 IC（Bridge/Repeater）② USB4/TBT4 Retimer ③ USB-C PD 控制器 ④ MST Hub IC
主要客戶全球 PC/螢幕 OEM：Dell、HP、Lenovo、Acer、Apple 周邊、Samsung 顯示器等
生產模式Fabless（設計為主，製造委外台積電/聯電）；OSAT 封測外包
市場地位DisplayPort Bridge IC 全球市佔率第一；USB4 Retimer 市場快速切入中
成長引擎AI 伺服器 PCIe/USB4 Retimer（高速信號再生）、DP 2.1 顯示器升級換機潮
競爭對手Realtek（瑞昱）、MegaChips（日本）、Texas Instruments（部分市場）
KY 結構開曼群島設立，實際營運在台灣；KY 股通常流動性略低於一般上市股
🔑 競爭優勢（護城河）：
1. 技術認證壁壘：DisplayPort 2.1 標準認證需要數年，已獲主流 OEM 設計導入，後進者難取代
2. 客戶黏著度高：IC 換供應商需重新驗證（3-6個月），Dell/HP 等大廠輕易不換
3. USB4/Retimer 卡位：AI 伺服器內部互連（PCIe Gen5/6）需大量 Retimer，譜瑞已有產品切入
4. 穩定高毛利率：約 40-43%，顯示技術差異化有定價能力（vs 一般晶片廠 30-35%）

📚 名詞小教室（本次報告 8 個術語）
Fabless（無晶圓廠模式）
只做晶片設計，不自己蓋工廠，把製造委外給台積電等專業代工廠。好處是資本支出低、可快速推出新產品；壞處是毛利受代工廠報價和供貨影響。
DisplayPort 2.1 IC
連接電腦與螢幕的數位傳輸標準 2.1 版，最高支援 80Gbps 頻寬（可傳 8K 240fps）。譜瑞做的 IC 負責在 DP 訊號和 HDMI 訊號之間轉換，是每台支援 DP 2.1 的螢幕都必須用到的零件。
Retimer IC
高速數位信號在傳輸過程中會衰減失真，Retimer 晶片負責「重新整形、放大、再生」信號，使長距離傳輸不出錯。AI 伺服器內部 PCIe Gen5/6 連線大量需要 Retimer。
OSAT 成本
OSAT = 外包半導體封裝測試廠（如日月光）。Fabless 設計好的晶片需委外封裝和測試，這部分費用稱 OSAT 成本。OSAT 成本偏高是譜瑞毛利率壓縮的主因之一。
KY 股
在台灣掛牌但公司設在開曼群島（Cayman Islands）的股票。KY = Cayman 的縮寫。法律上是外國公司，享受較低股利稅率，但資訊揭露和退場機制與一般台股略有不同，流動性可能偏低。
TTM EPS（近四季 EPS）
Trailing Twelve Months，取最近 4 個季度 EPS 的總和。比單一年度更即時。譜瑞 TTM EPS = Q3'25(10.45)+Q4'25(6.88)+Q1'26(6.77)+Q2'26(7.66) = 31.76元。
FactSet 共識
FactSet 是專業財務資料服務商，匯集多家券商分析師的盈利預測取平均。「共識目標價 578元」代表 17 家分析師的平均預期，是市場目前的「集體智慧」定價。
下降通道
股價走勢圖上，連接每次反彈高點形成的下傾趨勢線（壓力）和連接每次低點的另一條下傾線（支撐）。在通道內，股價上漲後又被賣回，稱為「下降通道格局」，代表多頭尚未反攻。
